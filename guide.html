📚 How to Use

Complete Guide to Image Optimization

🖼️ Image Converter - Quick Start

Step 1: Upload Your Images

  1. Click on the "Image Converter" card from the home page
  2. Drag and drop images OR click to browse
  3. Supports: JPG, PNG, GIF, BMP, WEBP

Step 2: Choose Dimension Preset

  • Original - Keep original size
  • Hero (1920px) - For website banners
  • Content (1200px) - For blog/article images
  • Thumbnail (600px) - For previews and grids

Step 3: Adjust Quality (Optional)

Use the quality slider (1-100%). Default is 85% for optimal balance.

Step 4: Download

  • Convert & Download All - Download images one by one
  • 📦 Download as ZIP - Bundle all images in one file
💡 Pro Tip: The tool automatically compresses images to 10-100KB range for fast web loading while maintaining HD quality!

✂️ Cropping Images

  1. Click the "Crop" button on any uploaded image
  2. Choose aspect ratio:
    • Free - Crop freely
    • 1:1 (Square) - Perfect square
    • 1:1 (DP) - Square with circular guide (for profile pictures)
    • 16:9 - Widescreen
    • 9:16 - Vertical (Instagram Stories)
    • 1200x675 - Standard web size
  3. Drag to adjust crop area
  4. Click "Apply Crop"

✨ Image Enhancement

Click the "✨ Enhance" button to automatically improve:

  • Brightness (+5%)
  • Contrast (+15%)
  • Saturation (+15%)

🎯 Icons Generator

Generate Favicons & App Icons

  1. Go to "Icons Generator" from home page
  2. Upload a square image (recommended: 512x512px or higher)
  3. Preview all generated sizes
  4. Click "📦 Download All Icons as ZIP"

What You Get:

  • Web Favicons: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
  • iOS Icons: 180x180, 192x192
  • Android Icons: 512x512
  • ICO File: Multi-size favicon.ico

🔒 Privacy & Security

  • ✅ All processing happens in your browser
  • ✅ No images are uploaded to any server
  • ✅ No data is stored or tracked
  • ✅ 100% private and secure

🖼️ इमेज कन्वर्टर - त्वरित शुरुआत

चरण 1: अपनी इमेज अपलोड करें

  1. होम पेज से "Image Converter" कार्ड पर क्लिक करें
  2. इमेज को ड्रैग एंड ड्रॉप करें या ब्राउज़ करने के लिए क्लिक करें
