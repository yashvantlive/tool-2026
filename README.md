# 🚀 Ultra-HD Pixel Machine - 2026 Tool Portal

A high-performance, browser-native image optimization platform with advanced compression and icon generation capabilities.

## ✨ Features

### 🎨 Ultra-HD Image Converter
- **Binary Search Quality Optimization** - Finds the perfect quality/size balance
- **10-100KB Smart Compression** - Ideal for web and mobile
- **Pixel-Aware Processing** - Maintains HD clarity even at low file sizes
- **Advanced Cropping** - Multiple aspect ratios with circular guide for profile pictures
- **One-Click Enhancement** - Brightness, contrast, and saturation optimization

### 📦 Edu-Marketing Enhancements
- **Batch ZIP Download** - Bundle all converted images in one click
- **Before/After Comparison** - Real-time file size reduction stats
- **Web Dimension Presets**:
  - Hero (1920px) - For banners
  - Content (1200px) - For articles
  - Thumbnail (600px) - For previews

### 🎯 Icons Generator
- **Multi-Platform Support** - Web, iOS, and Android icons
- **Instant Previews** - See all sizes (16px to 512px)
- **ZIP Bundling** - Download all icons at once

## 🚀 Quick Start

### Local Development
```bash
# Clone the repository
git clone https://github.com/yashvantlive/tool-2026.git
cd tool-2026

# Run local server
npx serve .
```

Open `http://localhost:3000` in your browser.

### Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yashvantlive/tool-2026)

Or using Vercel CLI:
```bash
npm install -g vercel
vercel
```

## 🛠️ Technology Stack

- **Frontend**: Pure HTML5, CSS3, JavaScript (ES6+)
- **Image Processing**: Canvas API, Binary Search Algorithm
- **Libraries**: 
  - Cropper.js (Advanced cropping)
  - JSZip (Batch downloads)
- **Performance**: Browser-native processing, no server required
