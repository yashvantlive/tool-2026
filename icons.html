Frequently Asked Questions

What is the Icons Generator?

It is a browser-native icon generator that takes a single high-resolution square logo and generates a package containing all required favicons and app icons for iOS, Android, and Web browsers.

What sizes does the generator produce?

The tool generates:

  • Web Favicons: 16×16, 32×32, 48×48, 192×192, 512×512, and a multi-resolution `.ico` file.
  • iOS App Icons: 120×120, 152×152, 167×167, 180×180.
  • Android App Icons: 48×48, 72×72, 96×96, 144×144, 192×192.

What formats are generated?

It outputs highly optimized PNG files for maximum device compatibility, a classic multi-size `.ico` favicon, and compiles the entire bundle into a single ZIP archive for easy download.

Does the Icons Generator store my images?

No. The generator operates entirely client-side. The image is processed in your browser's active memory using HTML5 Canvas and is never transmitted over the internet or saved on any server.
